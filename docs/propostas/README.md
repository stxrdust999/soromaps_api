# 🧪 Propostas

Material **adiantado** de decisões futuras: spec técnico escrito antes de a
mudança existir no código, para o time revisar e o implementador seguir.

Não confundir com as pastas vizinhas:

| Pasta | O que guarda |
|---|---|
| `docs/wiki` | O que **está** implementado (e o que foi projetado no TCC) |
| `docs/todo` | Backlog de produto já **comprometido**, um `.md` por módulo |
| `docs/propostas` | O que ainda **não** existe — desenho técnico aguardando implementação |

Cada proposta abre com um bloco de status dizendo em que pé está (rascunho,
conceito aprovado, implementada). Proposta implementada **sai daqui**: o
conteúdo migra para `docs/wiki` e o arquivo vai para `docs/archive`, seguindo
a regra do projeto de nunca apagar material obsoleto.
