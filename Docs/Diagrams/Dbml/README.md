# Modelagem DBML (Database Markup Language)

Os arquivos desta pasta contêm as definições formais das tabelas, chaves e relacionamentos prontas para importação ou visualização gráfica no **[dbdiagram.io](https://dbdiagram.io)**.

## 📄 Arquivos

- **[`Schema.dbml`](./Schema.dbml)**: Modelo completo do banco de dados consolidado.
- **[`Modules/Users.dbml`](./Modules/Users.dbml)**: Recorte focado no módulo de usuários e sessões.

## 🚀 Como Visualizar
1. Acesse [dbdiagram.io](https://dbdiagram.io).
2. Cole o código de `schema.dbml` ou de qualquer módulo no editor da esquerda.
3. O diagrama visual interativo será renderizado automaticamente.
